\# Neo Grid Gaming - E-commerce



\## Descripción

Proyecto de e-commerce desarrollado con Flask y MySQL como parte de la evidencia GA7-220501096-AA2-EV01.



\## Funcionalidades

\- Gestión de inventario (CRUD completo para administradores).

\- Sistema de autenticación con roles (Cliente/Admin).

\- Carrito de compras persistente.



\## Instrucciones de ejecución

1\. Instalar dependencias: `pip install -r requirements.txt`

2\. Importar `database\_schema.sql` en MySQL.

3\. Configurar variables de entorno en archivo `.env`.

4\. Ejecutar con: `python app.py`
